# Queer Connections 🏳️‍🌈

A LGBTQIA+ themed take on the "group the sixteen tiles into four hidden sets" puzzle, built for Pride. Find the four groups of four and watch out for the deliberate traps! Each solved group reveals a short note about the term's history ✨

Plays entirely in the browser. No build step, no dependencies, no tracking.
